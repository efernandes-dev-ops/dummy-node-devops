# Contributing to dummy-node-devops

We welcome contributions! Here's how you can help make this project better.

## How to Contribute

- **Report Issues**: Found a bug? Open an issue with details and steps to reproduce.
- **Suggest Features**: Have an idea? Submit an issue describing your enhancement.
- **Submit Pull Requests**: Ready to code? Fork the repo and submit a PR!

## Development Setup

1. Ensure you have Node.js installed (the project uses Node.js 5+)
2. Clone the repository: `git clone https://github.com/efernandes-dev-ops/dummy-node-devops.git`
3. Install dependencies: `npm install`
4. Run the application: `node index.js`

The project includes Docker support (`Dockerfile`) and Jenkins CI/CD configuration (`Jenkinsfile`). Build and run the Docker container locally to test changes in a containerized environment.

## Testing

Tests are being set up. Check `package.json` for the test script. Run tests with: `npm test`

## Pull Request Process
1. Create a feature branch from `master` (e.g., `feature/my-awesome-feature`)
2. Make your changes with clear, descriptive commit messages
3. Ensure your code follows existing project style and structure
4. Submit your PR with a clear description of changes and reference any related issues

Thanks for contributing! 🎉
